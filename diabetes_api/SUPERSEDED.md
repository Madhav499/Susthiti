# Superseded

This service (the 16-question symptom model, `diabetes_all_age_gender_model.joblib`) has been
replaced by the **SUSTHITI Future Diabetes Risk API v4** in `../diabetes_risk_api/`.

It is no longer started by `start-susthiti.bat` or deployed. Assessments made with it stay in each
patient's history (read-only). Kept here for reference only.
